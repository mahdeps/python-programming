المفهوم وأهم الخصائص

بايثون = لغة برمجة؛ الطريقة اللي بنعطي فيها الكمبيوتر أوامر. المميز فيها إنها أقرب لغة للإنجليزي العادي — عشان هيك مثالية للمبتدئين.

عشان تطبع كلمة على الشاشة… سطر واحد بس:

hello.py
print("مرحبا بالعالم 🐍")

هل تعلم؟ 🧠 اسم «بايثون» مش جاي من الأفعى! مخترعها Guido van Rossum كان بيحب برنامج كوميدي اسمه Monty Python فسمّاها عليه — والأفعى صارت بس الشعار.

  • ✓سهلة — أقرب لغة للإنجليزي
  • ✓مجانية ومفتوحة المصدر — بدون تراخيص
  • ✓تشتغل عَ كل الأنظمة — ويندوز، ماك، لينكس، وحتى الموبايل
  • ✓مكتبات جاهزة لكل إشي + مجتمع ضخم

⚙️ أساسيات البرمجة

٤ ركائز نبني عليها أي برنامج

١) المتغيرات (Variables): تخيّلها «علبة» بتحطّ فيها معلومة وبتسمّيها اسم تستعمله بعدين.

vars.py
name = "محمد"
age  = 22

print(name)
print(age)

٢) أنواع البيانات: نص str · رقم صحيح int · رقم عشري float · صح/غلط bool

٣) الإدخال والإخراج: نخلّي البرنامج يحكي معنا — input بتسأل، وprint بتطبع.

greet.py
name = input("شو اسمك؟ ")
print("أهلاً وسهلاً يا " + name + "! 👋")

٤) القرارات والتكرار: الشروط if / else بتخلّي البرنامج «يفكّر»، والحلقات for بتكرّر الأوامر بدالك.

🎯 نبني أداة حقيقية

تطبيق عملي واقعي · مولّد كلمات السر

بما إنّ مجالنا أمن سيبراني… خلّينا نبني مولّد كلمات سر قوية ببضع أسطر. أداة بتولّد باسوورد عشوائي صعب يتكسر 👇

password_gen.py
import random
import string

# كل الحروف والأرقام والرموز
chars = string.ascii_letters + string.digits + "!@#$%^&*"

# نولّد كلمة سر طولها 12 خانة
password = ''.join(random.choices(chars, k=12))

print("🔐 كلمة السر القوية:")
print(password)

↙ والأحلى؟ النسخة الشغّالة من نفس الفكرة موجودة تحت — جرّبها بإيدك.
